## 📱 Использование QR-маркировки в цеху

1. Каждая деталь имеет собственный QR-код высокого разрешения (`<Имя_детали>_qr.png`).
2. QR-код наносится на деталь лазерным маркером или распечатывается на термопринтере на клейкой этикетке.
3. Сканирование камерой смартфона открывает 3D-модель детали с возможностью вращения на 360°, зума и технологической картой (материал, толщина, порошковая покраска, инструкции).
4. Режим **AR** (дополненная реальность) позволяет примерить компонент в реальном масштабе.
